## Descrição do Desafio
Este projeto é um gerenciador de tarefas acadêmicas construído em Angular. A aplicação permite o cadastro, listagem, conclusão, reabertura e exclusão de tarefas. O sistema também realiza a contagem automática do total de tarefas e das tarefas pendentes, utilizando recursos fundamentais do framework como Signals, interpolação, controle de fluxo (`@if`, `@for`, `@empty`) e property/event bindings.

## Pré-requisitos
Certifique-se de ter as seguintes ferramentas instaladas:
* Node.js (versão 22 ou superior recomendada)
* npm (gerenciador de pacotes do Node)
* Angular CLI

## Como instalar
1. Faça o clone deste repositório em sua máquina local.
2. Abra o terminal e acesse a pasta do projeto:
   ```bash
   cd pauta-academica
   ```
3. Instale as dependências do projeto executando:
   ```bash
   npm install
   ```

## Como rodar
1. Com o terminal aberto na pasta do projeto (`pauta-academica`), inicie o servidor de desenvolvimento do Angular:
   ```bash
   npm start
   ```
   *Ou alternativamente:*
   ```bash
   ng serve --open
   ```
2. O navegador será aberto automaticamente na URL `http://localhost:4200/` exibindo a aplicação.
